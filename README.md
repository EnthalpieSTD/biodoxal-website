# Biodoxal — site web

Site vitrine de Biodoxal : métabolites secondaires d'origine microbienne (lipopeptides cycliques, polycétides, bactériocines) produits dans des châssis bactériens ingénierés, pour l'agriculture durable et l'industrie pharmaceutique.

Page unique autonome (`index.html`, polices intégrées) — aucune dépendance ni étape de build. Ouvrir le fichier dans un navigateur, ou publier via GitHub Pages (Settings → Pages → branche `main`, dossier `/`).
